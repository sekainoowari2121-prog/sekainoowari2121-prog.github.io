RRplayer（以下「本アプリ」）が取り扱う情報と、その利用目的・保管方法・削除方法について説明します。

アプリについて プライバシーポリシー

1. 基本方針

本アプリは、開発者が個人で利用するために開発したAndroid向け音楽再生アプリです。

本アプリは、独自のサーバーを一切持ちません。利用者の情報および音楽データが、開発者または第三者の管理するサーバーへ送信されることはありません。通信の相手先は、利用者ご自身のGoogleアカウントに紐づくGoogleのサービスのみです。

2. 本アプリが取得する情報

2.1 Googleアカウントに関する情報

Google Driveへ接続する際、利用者が許可した範囲で次の情報を取得します。

取得する情報利用目的
Googleアカウントのメールアドレス、および表示名どのアカウントに接続しているかを画面に表示するため。複数アカウントの取り違えを防ぐため
Google Driveへの接続を許可する情報（アクセストークン）Google Driveのファイルを読み取るため

接続を許可する情報は、Android端末のGoogle Play開発者サービスが管理し、本アプリはこれを端末の外へ持ち出しません。

2.2 Google Drive上のファイルに関する情報

本アプリは、次の権限を1つだけ要求します。

https://www.googleapis.com/auth/drive.readonly

Google Drive内のファイルを読み取るためだけの権限です。

この権限を用いて取得する情報と、その目的は次のとおりです。

取得する情報利用目的
フォルダおよびファイルの名前・識別番号・形式・サイズ・更新日時音楽ライブラリの一覧を表示し、同じ曲を重複して扱わないよう識別するため
音楽ファイルの内容楽曲を再生するため。および利用者が明示的に指定した楽曲を端末へ保存するため
音楽ファイルに含まれる曲名・アーティスト名・アルバム名・曲番号などの情報ライブラリの表示・検索・並べ替えのため
プレイリストファイル（M3U / M3U8）の内容プレイリストを再現するため

2.3 取得しない情報

  • Googleアカウントのパスワードおよび二段階認証の情報（本アプリが受け取ることはありません）
  • 連絡先、カレンダー、メール、写真などGoogle Drive以外のGoogleサービスの情報
  • 端末の位置情報
  • 利用者の操作履歴を分析するための情報。本アプリは解析ツールおよび広告を一切組み込んでいません

3. 本アプリが行わないこと

  • Google Drive上のファイルの作成・変更・削除・移動・名前の変更を行いません。読み取りのみを行います。
  • 取得した情報を、開発者または第三者のサーバーへ送信しません。
  • 取得した情報を、第三者へ提供・販売・貸与しません。
  • 取得した情報を、広告の表示や配信のために利用しません。
  • 取得した情報を、人工知能・機械学習モデルの開発や学習のために利用しません。
  • 音楽の再生および利用者が指示した保存以外の目的で、情報を利用しません。

4. 情報の保管場所と保管期間

本アプリが取得した情報は、すべて利用者の端末内のみに保管されます。保管場所は、他のアプリから読み取れないアプリ専用の領域です。

保管するもの保管期間
ライブラリの情報（曲名・保存場所の識別番号など）利用者が曲を一覧から削除するまで、またはアプリを削除するまで
再生を安定させるために一時的に蓄えた音楽データ最大1GBまで。利用者が設定した期間（1週間・2週間・1か月）を過ぎると自動的に削除されます。上限に達した場合は古いものから削除されます
利用者が明示的に端末へ保存した音楽ファイル利用者が削除するまで保持されます。上記の自動削除の対象にはなりません
音質の設定、接続機器ごとの設定利用者が削除するまで、またはアプリを削除するまで
Google Driveへの接続を許可する情報Google Play開発者サービスが管理します。利用者が接続を解除するか、Google側で許可が失効するまで

5. 情報の削除方法

利用者は、いつでも次の方法で情報を削除できます。

  • 一時的に蓄えたデータを消す：本アプリの設定画面から削除します。明示的に保存した音楽ファイルは消えません。
  • 保存した音楽ファイルを消す：曲の一覧から個別に削除します。
  • すべての情報を消す：Androidの設定から本アプリをアンインストールします。端末内に保管された情報はすべて削除されます。
  • Google Driveへの接続を解除する：Googleアカウントの管理画面（アカウントにアクセスできるアプリ）からRRplayerを削除します。これにより、本アプリはGoogle Driveを読み取れなくなります。

6. Googleユーザーデータの限定利用について

本アプリによるGoogle APIから取得した情報の利用および他アプリへの移転は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に準拠します。

7. 安全管理

  • Googleとの通信は、すべて暗号化された経路（HTTPS）で行います。
  • 本アプリは利用者のパスワードを受け取らず、保存もしません。
  • 端末内に保管する情報は、他のアプリから読み取れないアプリ専用の領域に置きます。

8. 未成年の利用について

本アプリは開発者が個人で利用するためのものであり、児童を対象としたサービスではありません。児童の個人情報を意図的に収集することはありません。

9. 本ポリシーの変更

本アプリの機能変更にともない、本ポリシーを変更する場合があります。変更した場合は、本ページの内容と下部の改定日を更新します。

Privacy Policy (English summary)

RRplayer is a personal, non-commercial Android music player. It has no developer-operated server. No user data is ever transmitted to the developer or to any third party.

RRplayer requests one OAuth scope, https://www.googleapis.com/auth/drive.readonly, which it uses only to list the user's own music folders, read file and track metadata, read M3U / M3U8 playlist files, and stream or download the user's own music files for playback on the user's device. RRplayer never creates, modifies, deletes or moves any file in Google Drive.

All retrieved data is stored solely in the app's private storage on the user's device. Streaming cache is capped at 1 GB and is deleted automatically after a user-selected period (1 week, 2 weeks, or 1 month). Files the user explicitly downloads are kept until the user deletes them. Uninstalling the app removes all stored data. Access can be revoked at any time from the user's Google Account permissions page.

RRplayer does not use Google user data for advertising, does not sell or share it, and does not use it to develop, improve or train generalized AI or machine learning models. RRplayer's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
